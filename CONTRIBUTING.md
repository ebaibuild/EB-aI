# Contributing to E.B AI

Thanks for being interested in an early-stage project! Please start by opening an issue describing the problem or improvement you want to tackle before making large architectural changes.

## Good first areas

- Improve keyboard accessibility and screen reader labels.
- Add tests for workflow validation and edge cases.
- Improve mobile behavior and reduced-motion styling.
- Propose a precise, documented action-result schema.
- Review security and privacy assumptions.

## Local development

1. Install Node.js 20 or later.
2. Run `npm start` and visit `http://127.0.0.1:4173`.
3. Run `npm run check` before opening a pull request.
4. Describe what changed and how it was tested.

## Expectations

- Never commit tokens, credentials, private data, `.env` files, or screenshots containing account details.
- Make no unverified claims of adoption or feature completion.
- Keep external actions permissioned and auditable.
- Favor focused improvements with understandable tests.
- Be respectful and constructive in reviews.

For security issues, follow [SECURITY.md](./SECURITY.md) instead of publishing an exploit in an issue.
