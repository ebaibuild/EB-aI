# Roadmap — proposals, not promises

## Stage 0 · Public foundation (included here)
- [x] Publishable static project landing page
- [x] Browser-only task board with explicit user-controlled status
- [x] Safe JSON export and schema validation
- [x] Unit tests and local-only server
- [x] Public documentation and contribution guide
- [ ] Real maintainer contact details and repository URL (add only when known)
- [ ] Publish GitHub repository (must be performed by repository owner)

## Stage 1 · Shared interfaces (proposed)
- [ ] Define explicit action permission descriptors
- [ ] Design auditable, structured task execution results
- [ ] Implement offline test adapters before production services
- [ ] Create a security threat model

## Stage 2 · Model connectivity (proposed)
- [ ] Evaluate local and hosted models as optional adapters
- [ ] Add clear failure states for unavailable models and quota limits
- [ ] Document resource use and tradeoffs

## Stage 3 · Permissioned integrations (proposed)
- [ ] Separate OAuth secrets from public source code
- [ ] Per-tool authorization and revocation
- [ ] Verifiable results and visible action histories

## Stage 4 · Community (proposed)
- [ ] Publish contributor onboarding and community roadmap updates
- [ ] Label beginner-friendly issues when real tasks emerge
- [ ] Invite feedback and improve based on actual user research

No adoption metrics, features, or public release dates are claimed by this roadmap.
